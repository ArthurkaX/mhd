User Flow · v0.7.0

Claude Code & OpenAI clients through mHD

Two kinds of client point at one local endpoint. The proxy routes each request type to its matching surface — Anthropic Messages or OpenAI chat-completions — runs the native trim engine, then forwards upstream. You switch where each tier goes from the tray or a hotkey while the session stays open.

Two clients

Claude Code & OpenAI editors

Claude Code and editors like Zed both point at the same local proxy — each on its native API shape.

Compress

Native trim engine

A clean-room engine shrinks each outgoing request deterministically — no extra model call — with the prompt-cache prefix kept byte-identical.

Route

Native or side key

Send a tier to Anthropic native passthrough, or to an OpenAI-compatible provider with your own key.
