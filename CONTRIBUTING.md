# Contributing to mHD

Thanks for your interest in `mHD`.

## Development Policy

This project is maintained as a focused desktop utility. For now, I prefer to review issues and implement core changes directly so the UI, behavior, and public release shape stay consistent.

## What Helps Most

### Bug Reports

Please open an issue with:

- the Windows version;
- what action you were trying to perform;
- what you expected to happen;
- what actually happened;
- a short config snippet if the issue is binding-related.

### Feature Requests

If you want a new action or overlay:

- describe the workflow in practical terms;
- say which existing tool you would otherwise use;
- explain the shortcut or panel shape you expect.

### Compatibility Notes

If a hardware-dependent action behaves differently on your machine, include:

- monitor model;
- audio device details;
- power plan names;
- whether the issue reproduces with a clean config.
