# Security Policy

## Supported Versions

Security fixes are provided for the current `main` branch and the latest public release line.

## Reporting a Vulnerability

If you find a security issue, do not open a public issue.

Use private vulnerability reporting on GitHub or contact the repository owner directly.

Include:

- a short description of the issue;
- the affected version or commit;
- reproduction steps;
- whether the issue requires a specific config or hardware setup.

## Operational Notes

`mHD` runs locally on the user's machine and can execute user-configured actions. Review your config before sharing it, especially when it contains PowerShell commands or custom automation.
